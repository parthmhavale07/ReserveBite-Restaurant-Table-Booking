RESERVEBITE – RESTAURANT TABLE BOOKING SYSTEM

How to run:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser.
4. For best results, use VS Code Live Server.

Features:
- Responsive restaurant website
- Menu section
- Table availability by date and time
- Interactive table selection
- Booking confirmation with Booking ID
- My Booking search
- Booking cancellation
- LocalStorage data saving
- Dark mode
- Customer reviews
- Contact section

Technology:
HTML5, CSS3, JavaScript, LocalStorage

Note:
This is a frontend mini-project. Bookings are stored locally in the browser and are not connected to a real restaurant database.
